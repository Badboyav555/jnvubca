# Unit 1: Introduction to C Programming

## What is C Language?

C is a **general-purpose programming language** developed by **Dennis Ritchie** at Bell Labs in **1972**.

### Key Features:
- Fast and efficient
- Low-level memory access
- Structured language
- Portable across platforms
